## 2027 오픈소스 기여 후보 조사

조사일 → 2026-10-22 · 측정 구간 → 2026-07-23 ~ 2026-10-22 (90일)

토스 기여는 계속 이어가면서, 그 외에 **유명하면서 실제로 활발한** 저장소 한 곳을 더 고르기 위한 조사 기록입니다.

### 왜 스타 수만으로는 고를 수 없는가

머지량이 많아도 외부 사람이 들어갈 자리가 없는 저장소가 많습니다. 아래가 그 예입니다.

- `electron/electron` → 90일간 2,229건 머지, 그런데 사람은 5명
- `oven-sh/bun` → 2,007건 머지, 사람 5명
- `react/react-native` → 스타 12만, 90일간 머지 12건 (Meta 내부에서 개발해 깃허브로 동기화하는 구조)

그래서 "유명세 + 활발함 + **외부 개방성**" 세 축으로 측정했습니다.

### 측정 방법

GitHub API로 저장소 22곳을 직접 측정했습니다.

- **머지/90일** → 최근 90일간 머지된 PR 수
- **기여자 / 상위5 집중 / 1회 기여자** → 최근 머지 PR 100건의 작성자 분포. 상위 5명 비중이 낮을수록 외부에 열린 곳이고, 1회 기여자가 많을수록 처음 온 사람의 PR이 머지되는 곳입니다
- **머지 중앙값** → PR 생성부터 머지까지 걸린 시간의 중앙값
- **입문 이슈** → `help wanted`, `good first issue`, `contributions welcome` 라벨이 붙은 열린 이슈 수
- **점수** → `log10(스타) × 10 + log10(머지량) × 8 + (100 - 상위5 집중) × 0.45`

renovate, dependabot 같은 **봇은 집계에서 제외**했습니다. `astro`, `prettier`, `mui`는 최다 기여자가 봇이라 제외 전후 수치가 크게 달라집니다.

### 후보 3곳

#### 1. nodejs/node — 종합 1위

공식 깃허브 → https://github.com/nodejs/node

- 90일간 1,079건 머지, 외부 1회성 기여자 15명
- 재단이 운영해서 특정 회사 소속이 아니어도 들어갈 자리가 구조적으로 있음
- C++ 코어는 어렵지만 `lib/*.js`(JS 레이어)와 `doc/`은 접근 가능
- 단점 → 머지 중앙값 2.4일, 승인 규칙이 엄격함

#### 2. react/react — 네임밸류 최고

공식 깃허브 → https://github.com/react/react

- 스타 25만, 측정한 저장소 중 가장 유명
- 의외로 개방적 → 기여자 34명, 1회 기여자 21명, 머지 중앙값 0.9일
- 단점 → **입문용 이슈가 1개뿐**이라 스스로 거리를 찾아야 함
- 참고 → 조직명이 `facebook/react`에서 **`react/react`로 변경됨**

#### 3. nuxt/nuxt 또는 microsoft/TypeScript — 성격이 반대

- `nuxt` → 입문 이슈 32개, 머지 중앙값 0.1일. **가장 빨리 첫 머지를 만들 수 있는 곳.** 스타 6만으로 체급은 위 두 곳보다 낮음
- `TypeScript` → 입문 이슈 **773개**로 압도적이지만 상위 5명이 77%를 차지해 외부 머지는 어려움. 언어가 **Go**로 표시되는 이유는 TS 7 네이티브 포팅이 진행 중이기 때문

### 선택 전략

토스는 계속 하는 전제이므로 **새로 추가하는 곳은 한 곳만** 고릅니다. 새 저장소는 코드베이스 파악과 기여 규칙 익히는 데만 몇 주가 걸립니다.

- 네임밸류 우선 → `react/react` 또는 `nodejs/node`
- 빠른 성취감 우선 → `nuxt/nuxt`로 몇 건 쌓고 큰 곳으로 이동
- 둘 다 → `nuxt`로 흐름 익히고 `node`로 이동

### 측정의 한계

- 작성자 분포는 **최근 머지 100건** 표본입니다. `next.js`, `electron`처럼 머지량이 매우 많은 곳은 며칠치만 반영되어 다양성이 과소평가될 수 있습니다
- 입문 이슈 수는 라벨이 붙은 것만 셉니다. 라벨 운영을 안 하는 저장소(`react` 등)는 실제 기여 기회보다 적게 나옵니다
- 숫자는 2026-10-22 기준입니다. 분기마다 다시 재는 것이 좋습니다
